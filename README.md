# IsItJustMe? 🔌💧📶

### Problem Statement
When there's a power cut, water supply issue, or internet outage, people have no way to know if it's just their house or the whole area. They rely on calling neighbors, random WhatsApp forwards, or just waiting blindly — wasting time during already frustrating situations.

### Solution
IsItJustMe is a real-time community outage tracker. Anyone can report an outage (Power / Water / Internet) with their area, and others nearby can instantly see live reports and confirm it's happening to them too via a "Me too" button. Reports are automatically flagged as **Reported → Confirmed → Widespread Outage** based on how many people confirm it, so the community gets an instant, crowdsourced picture of what's really going on.

### Features
- Report outages by type and area
- Live real-time feed (powered by Firebase Firestore)
- "Me too" community confirmation counter
- Auto severity badges (🟡 Reported / 🟠 Confirmed / 🔴 Widespread)
- Category filters (Power / Water / Internet)
- Live stats dashboard (total reports, areas affected, confirmations)
- Fully responsive design

### Tech Stack
HTML, CSS, JavaScript, Firebase Firestore (real-time database)
